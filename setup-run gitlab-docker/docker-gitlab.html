1. GitLab Kya Hai?

GitLab ek DevOps platform hai jisme source code management, Git repositories, collaboration, CI/CD aur software development lifecycle ke multiple features available hote hain.

Is practical me hum GitLab ko directly apne Ubuntu system par install karne ke bajay Docker container ke andar run karenge.

Goal:
Docker Hub se GitLab Community Edition image pull karna → Container run karna → Browser se GitLab open karna → Initial root password nikalna → GitLab me root user se login karna.

2. GitLab Ko Docker Me Kyu Run Kare?

  • Installation process relatively isolated hota hai.
  • GitLab ko container ke andar run kar sakte hain.
  • Host operating system ko directly modify karne ki requirement kam hoti hai.
  • Docker commands se container lifecycle manage kar sakte hain.
  • DevOps learning ke liye practical environment milta hai.
Ubuntu Host | v Docker Engine | v GitLab Container | +---- GitLab Web UI | +---- Git Repository | +---- CI/CD Features

3. Requirements

GitLab container run karne se pehle ensure karo ki Docker working hai. 

docker --version

Docker information check: 

docker info
Agar Docker daemon running nahi hai to GitLab container bhi run nahi hoga.

8. Important: Ye Command Foreground Me Run Hoti Hai

Agar aap: 

docker run -p 8000:80 gitlab/gitlab-ce

run karte ho, to container foreground me run hota hai aur terminal GitLab ke logs show kar sakta hai.

Is situation me doosra terminal open karke Docker commands run kar sakte ho.

Agar background me run karna ho to -d use kar sakte ho: 
docker run -d -p 8000:80 --name gitlab gitlab/gitlab-ce

9. Step 3 — Chrome Me GitLab Open Karna

Container start hone ke baad Chrome me new tab open karo.

Address bar me: 

http://localhost:8000

Enter press karo.

Agar GitLab initialization complete ho chuki hai, to GitLab login page available ho sakta hai.
GitLab ek large application hai aur first startup me time lag sakta hai. Isliye container start hote hi browser page immediately ready na ho, to thoda wait karke refresh karo.

12. Container ID Kya Hai?

Docker har container ko ek unique identifier deta hai, jise container ID kehte hain. 

CONTAINER ID
a1b2c3d4e5f6

Aap commands me full ID ya generally enough unique short ID use kar sakte ho.

Example ke liye hum a1b2c3d4e5f6 use kar rahe hain. Apne system par actual container ID alag hogi.

13. Step 6 — GitLab Initial Root Password Nikalna

GitLab initial root password container ke andar file me stored hota hai: 

/etc/gitlab/initial_root_password

Container ke andar file read karne ke liye: 

docker exec -it CONTAINER_ID cat /etc/gitlab/initial_root_password

Example: 

docker exec -it a1b2c3d4e5f6 cat /etc/gitlab/initial_root_password

Command Breakdown

Part Meaning
docker Docker CLI.
exec Running container ke andar command execute karna.
-it Interactive terminal mode.
CONTAINER_ID Target GitLab container.
cat File ka content display karna.
/etc/gitlab/initial_root_password Initial root password file.

14. Password Output Ko Samajhna

Initial root password temporary setup credential hai. Is password ko securely handle karo aur GitLab setup ke baad appropriate password change/security practices follow karo.

Password ko copy kar lo.

GitLab startup process ko monitor karne ke liye:

  • GitLab page open nahi ho rahi ho.
  • Container startup complete nahi hua ho.
  • Application initialization me problem ho.

20. docker exec Kya Karta Hai?

docker exec running container ke andar command execute karne ke liye use hota hai.

General Syntax

docker exec [OPTIONS] CONTAINER COMMAND

Example

docker exec -it gitlab bash

Isse container ke andar interactive shell open ki ja sakti hai.

Direct file read: 

docker exec -it gitlab cat /etc/gitlab/initial_root_password

21. Important Command Correction

Incorrect: 
docker exex -it container_id cat/etc/gitlab/initial_root_password
Correct: 
docker exec -it CONTAINER_ID cat /etc/gitlab/initial_root_password

Do important corrections:

  1. exex nahi, exec.
  2. cat aur file path ke beech space.

22. Initial Root Password Ke Baare Me Important Note

GitLab ke Docker setup me generated initial root password installation ke initial period me available hota hai.

Isliye GitLab start karne ke baad initial password ko jaldi retrieve kar lena useful hai.

Agar initial password available nahi mil raha hai, to container logs, GitLab initialization status aur container configuration check karo.

23. GitLab Data Persistence — Important

Abhi humne simple command se GitLab run kiya: 

docker run -d \
  --name gitlab \
  -p 8000:80 \
  gitlab/gitlab-ce

Learning ke liye ye fine hai, lekin real usage me GitLab ka configuration, logs aur application data persist karna important hota hai.

Isliye production-like setup me GitLab ke persistent directories ko Docker volumes/bind mounts ke saath map kiya jata hai.

Is chapter ka primary focus GitLab image pull → container run → initial password → login workflow hai. Persistent GitLab storage ko next advanced practical me separately configure karna better hai.

24. GitLab Container Stop & Remove

Stop

docker stop gitlab

Start Again

docker start gitlab

Remove

docker rm gitlab
Container remove karne se pehle ensure karo ki required GitLab data persistent storage me safely maintained hai.

25. Common Problems & Solutions

Problem 1 — Port 8000 Already in Use

Bind for 0.0.0.0:8000 failed:
port is already allocated

Check: 

docker ps

Ya different host port use karo: 

docker run -d \
  --name gitlab \
  -p 8001:80 \
  gitlab/gitlab-ce

Ab browser: 

http://localhost:8001

Problem 2 — Browser Me Page Nahi Khul Rahi

Container check: 

docker ps

Logs: 

docker logs gitlab

Problem 3 — GitLab Startup Slow

GitLab ek large application hai. First startup me initialization time lag sakta hai.

Logs monitor karo: 

docker logs -f gitlab

Problem 4 — Initial Password File Nahi Mil Rahi

Pehle check karo ki container running hai: 

docker ps

Phir: 

docker exec -it gitlab cat /etc/gitlab/initial_root_password

Problem 5 — Container Name Already Exists

Conflict. The container name "/gitlab" is already in use.

Existing container check: 

docker ps -a

Agar old container remove karna safe ho: 

docker rm -f gitlab
Warning: docker rm -f running container ko forcefully remove kar sakta hai. Important data ho to pehle persistence check karo.
