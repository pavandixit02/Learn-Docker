1. Play with Docker Kya Hai?

Play with Docker (PWD) ek browser-based Docker playground hai jahan hum Docker commands aur containers ko cloud environment me practice kar sakte hain.

Iska main purpose Docker ko practice karna hai bina apne local computer par complete Docker environment configure kiye.

Simple Definition:
Play with Docker ek temporary online Docker environment hai jahan aap Docker images, containers aur Docker commands ko practically run karke practice kar sakte ho.

Real-Life Analogy

Maan lo aapke laptop me Docker install nahi hai, lekin aap Docker commands practice karna chahte ho.

PWD ko aap ek temporary online Docker laboratory ki tarah samajh sakte ho.

2. Play with Docker Ki Zarurat Kyu Hoti Hai?

  • Docker commands practice karne ke liye.
  • Docker containers run karne ke liye.
  • Docker images test karne ke liye.
  • Docker Hub images pull karne ke liye.
  • Networking concepts practice karne ke liye.
  • Docker Compose practice karne ke liye.
  • Cloud-like temporary environment me Docker seekhne ke liye.
PWD learning aur experimentation ke liye useful hai. Production hosting ke replacement ke roop me ise treat nahi karna chahiye.

3. Local Docker vs Play with Docker

Local Docker Play with Docker
Apne laptop/PC par Docker run hota hai. Browser-based temporary Docker environment.
Local files directly available. Environment remote/temporary hota hai.
Long-term development ke liye useful. Learning/testing ke liye useful.
Resources aapke computer par depend karte hain. Temporary cloud environment provide karta hai.

7. Local compose.yaml

Previous part me humne Compose file banayi thi. Yahan uska simplified version use karenge. 

services:

  app:

    build:
      context: .
      dockerfile: dockerfile

    image: node-docker-app:1.0

    container_name: node-app-compose

    ports:
      - "3000:3000"

    volumes:
      - node-app-data:/app/data

    environment:
      NODE_ENV: production

    restart: unless-stopped

volumes:

  node-app-data:

Ye Compose file local Dockerfile se image build kar sakti hai.

8. Compose File Se Image Build Karna

Project directory me jao: 

cd node-app-mini

Compose configuration check karo: 

docker compose config

Ab image build karo: 

docker compose build

Check:

Image: 

node-docker-app:1.0
Ab hamare paas local Docker image ready hai.

9. Play with Docker Tak Image Kaise Pahunchegi?

PWD ek separate environment hai. Aapke local computer par bani image automatically PWD me available nahi hoti.

Isliye image ko ek Docker Registry par push karna convenient workflow hai. Learning ke liye hum Docker Hub use karenge.

Local Docker | | docker build v Local Image | | docker tag v Docker Hub Image Name | | docker push v Docker Hub | | docker pull v Play with Docker

10. Docker Hub Login

Terminal me Docker Hub login: 

docker login

Apne Docker Hub credentials ke according authentication complete karo.

Password ko source code, README, Dockerfile ya compose.yaml me hard-code mat karo.

11. Local Image Ko Docker Hub Name Dena

Local image: 

node-docker-app:1.0

Docker Hub repository: 

pavandixit/node-docker-app

Tag command: 

docker tag node-docker-app:1.0 pavandixit/node-docker-app:1.0

Check: 

docker images

Ab image ke paas Docker Hub compatible tag hai.

12. Docker Hub Par Image Push Karna

docker push pavandixit/node-docker-app:1.0

Docker image ke layers Docker Hub registry par upload honge.

Push complete hone ke baad PWD jaise external Docker environment image ko Docker Hub se pull kar sakte hain.

13. Play with Docker Open Karna

Playground ke andar Docker environment/instance create karo.

PWD ka interface time ke saath change ho sakta hai, isliye buttons/labels ka exact text version ke according different ho sakta hai.

16. PWD Me Image Directly Run Karna

Image pull karne ke baad directly container run kar sakte ho:

  --name node-app-pwd \
  -p 3000:3000 \
  pavandixit/node-docker-app:1.0

Check: 

docker ps

Logs: 

docker logs node-app-pwd

17. PWD Me Port Access

Local computer par hum normally: 

http://localhost:3000

use karte hain.

PWD me container remote playground instance par run ho raha hota hai, isliye PWD ka provided port-access mechanism use karke exposed application ko browser me open karna hota hai.

Important Concept:
-p 3000:3000 container port ko instance ke accessible port se expose karta hai. PWD interface us port ko browser me open karne ka option provide karta hai.

18. PWD Me Compose Ke Saath Run Karna

Agar PWD me Compose use karna hai aur image Docker Hub par available hai, to local build ke instead registry image reference karna convenient hai.

PWD me compose.yaml create karo: 

services:

  app:

    image: pavandixit/node-docker-app:1.0

    container_name: node-app-pwd

    ports:
      - "3000:3000"

    volumes:
      - node-app-data:/app/data

    environment:
      NODE_ENV: production

    restart: unless-stopped

volumes:

  node-app-data:
Yahan build: intentionally remove kiya gaya hai, kyunki PWD me hum Docker Hub se already-built image use kar rahe hain.

27. Kya PWD Me Dockerfile Se Direct Build Kar Sakte Hain?

Haan, agar aapka source code aur Dockerfile PWD instance me available hai, to Docker image locally build ki ja sakti hai. 

docker build -t node-docker-app:1.0 .

Lekin hamare current workflow me: 

Local Build
    ↓
Docker Hub Push
    ↓
PWD Pull
    ↓
Run

use karna easier hai, kyunki PWD ko source project files dene ki zarurat nahi padti.

28. Common Problems

Problem 1 — Image Pull nahi ho rahi

pull access denied

Possible reasons:

  • Repository name incorrect.
  • Tag incorrect.
  • Repository private hai.
  • Authentication required hai.

Problem 2 — Port access nahi ho raha

Check: 

docker ps

Aur container logs: 

docker logs node-app-pwd

Problem 3 — Container immediately stop ho gaya

Logs check karo: 

docker logs node-app-pwd

Problem 4 — Compose command issue

docker compose version

Docker Compose availability/version check karo.

29. Docker Hub Security

Never put secrets inside Docker images.

Passwords, API keys aur tokens ko Dockerfile me hard-code mat karo.

Example avoid karo: 

ENV PASSWORD=my-secret-password

Learning ke bahar real credentials ke liye secure secret-management approach use karo.

32. Play with Docker Interview Questions

Q1. Play with Docker kya hai?

Play with Docker ek browser-based temporary Docker playground hai jahan Docker commands aur container-based workloads ko practice kiya ja sakta hai.

Q2. Kya local Docker image directly PWD me available hoti hai?

Nahi. Local machine ki Docker image aur PWD ka Docker environment separate hote hain. Image ko registry jaise Docker Hub par push karke PWD se pull karna common workflow hai.

Q3. Docker Hub ka role kya hai?

Docker Hub ek container image registry hai jahan Docker images ko store aur distribute kiya ja sakta hai.

Q4. docker pull kya karta hai?

Registry se Docker image ko local Docker environment me download karta hai.

Q5. docker push kya karta hai?

Local Docker image ko registry repository me upload karta hai.

Q6. PWD me Compose kaise use kar sakte hain?

PWD instance me Compose file available honi chahiye. Registry image ke case me docker compose pull ke baad docker compose up -d se services start ki ja sakti hain.

Q7. PWD production hosting ke liye hai?

PWD primarily learning, practice aur experimentation ke liye designed playground environment hai; permanent production hosting ke liye dedicated infrastructure use karna chahiye.

33. Final Summary

  • Play with Docker ek browser-based Docker playground hai.
  • Iska use Docker learning aur experimentation ke liye kiya ja sakta hai.
  • Local Docker image PWD me automatically available nahi hoti.
  • Docker Hub registry ke through image distribute ki ja sakti hai.
  • docker tag image ko registry-compatible name deta hai.
  • docker push image ko Docker Hub par upload karta hai.
  • docker pull PWD me image download karta hai.
  • docker run image se container start karta hai.
  • Compose file me Docker Hub image ko image: ke through reference kar sakte hain.
  • docker compose pull Compose-defined images pull karta hai.
  • docker compose up -d Compose services ko background me start karta hai.
  • PWD temporary environment hai; production hosting ke liye dedicated infrastructure better hai.
