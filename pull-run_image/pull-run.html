🐳 Docker Image Pull & Run

Learn how to pull Docker images and run containers with practical examples using Nginx, Ubuntu, and Redis.

Concept Pull Run Nginx Ubuntu Redis Commands

1. Docker Image Pull & Run — Basic Concept

Docker me kisi application ko run karne ke liye commonly hume ek Docker Image ki zarurat hoti hai.

Agar image hamare local computer par available nahi hai, to hum us image ko kisi container registry, jaise Docker Hub, se pull kar sakte hain.

Image available hone ke baad hum us image se ek container create aur start kar sakte hain using docker run.

Docker Hub
→
docker pull
→
Local Image
→
docker run
→
Container
Easy Formula:

docker pull = Image ko download karo

docker run = Image se container create + start karo

2. Docker Image ko Pull Kaise Karte Hain?

docker pull command ka use kisi container registry se Docker image ko local machine par download karne ke liye kiya jata hai.

Basic Syntax

docker pull IMAGE_NAME

Example

docker pull nginx

Is command se Docker registry se Nginx image ka default tag pull kiya jayega.

Specific Tag Pull Karna

docker pull nginx:1.27

Yahan 1.27 image tag/version ko represent karta hai.

Pull ke Baad Image Check Karein

docker images

Ye command local machine par available Docker images dikhati hai.

3. Docker Image ko Run Kaise Karte Hain?

docker run command Docker image se container create aur start karne ke liye use hoti hai.

Basic Syntax

docker run IMAGE_NAME

Simple Example

docker run nginx

Docker image ko local machine par check karega. Agar image available nahi hai, Docker registry se image pull kar sakta hai, phir container create karke start karega.

Detached Mode

docker run -d nginx

-d ka matlab detached mode hai. Container background me run hota hai aur terminal immediately available rehta hai.

Container ko Custom Name Dena

docker run -d --name my-nginx nginx

Port Mapping

docker run -d --name my-nginx -p 8080:80 nginx

Isme:

  • 8080 = host machine ka port
  • 80 = container ka port

4. Example 1 — Nginx Image Pull & Run

🌐 Nginx Web Server

Step 1 — Pull Nginx Image

docker pull nginx

Step 2 — Verify Image

docker images

Step 3 — Run Nginx Container

docker run -d --name my-nginx -p 8080:80 nginx

Command Explanation

Part Meaning
docker run Container create aur start karta hai.
-d Container ko background me run karta hai.
--name my-nginx Container ko custom name deta hai.
-p 8080:80 Host port 8080 ko container port 80 se map karta hai.
nginx Use ki jane wali Docker image.

Step 4 — Check Container

docker ps

Step 5 — Browser Me Open Karein

http://localhost:8080
Expected Result:

Browser me Nginx ka welcome page display hona chahiye.

Step 6 — Container Logs

docker logs my-nginx

Step 7 — Container Stop

docker stop my-nginx

Step 8 — Container Remove

docker rm my-nginx

5. Example 2 — Ubuntu Image Pull & Run

🐧 Ubuntu Container

Step 1 — Pull Ubuntu Image

docker pull ubuntu

Step 2 — Check Image

docker images

Step 3 — Run Ubuntu Container

docker run -it --name my-ubuntu ubuntu

Command Explanation

  • -i = Interactive mode
  • -t = Allocate a terminal
  • --name my-ubuntu = Container ka custom name
  • ubuntu = Ubuntu image

Container ke Andar Commands Run Karein

cat /etc/os-release
ls
pwd

Container Se Exit

exit

Stopped Container Check Karein

docker ps -a
Important:

Ubuntu container me agar primary process exit ho jata hai, to container stop ho sakta hai. Ye normal container behavior hai.

6. Example 3 — Redis Image Pull & Run

⚡ Redis Container

Step 1 — Pull Redis Image

Step 2 — Run Redis

Step 3 — Check Container

Step 4 — Check Logs

GET name
Expected Result:

Redis me name key ke andar Pavan value store hogi.

Redis Container Stop

Redis Container Remove

7. docker pull vs docker run

docker pull docker run
Image ko registry se local machine par download karta hai. Image se container create aur start karta hai.
Container create nahi karta. Container create karta hai.
Example: docker pull nginx Example: docker run nginx
Image management ke liye useful. Application/container run karne ke liye useful.
Important:

docker run ko use karte waqt agar required image local machine par available nahi hai, Docker normally us image ko registry se pull karne ki koshish karta hai.

8. Important Commands After Running an Image

List Images

docker images

List Running Containers

docker ps

List All Containers

docker ps -a

View Container Logs

docker logs CONTAINER_NAME

Execute Command Inside Container

docker exec -it CONTAINER_NAME bash

Kuch minimal images me bash available nahi hota. Aise cases me image ke according sh use karna pad sakta hai. 

docker exec -it CONTAINER_NAME sh

Stop Container

docker stop CONTAINER_NAME

Start Existing Container

docker start CONTAINER_NAME

Remove Container

docker rm CONTAINER_NAME

9. Specific Image Version Pull & Run

Production aur professional Docker workflows me image tags ko samajhna important hai.

Specific Version Pull

docker pull nginx:1.27

Specific Version Run

docker run -d --name nginx-version -p 8080:80 nginx:1.27
Best Practice:

Learning ke liye latest tag convenient ho sakta hai, lekin production deployments me intentionally selected, tested aur controlled image versions/tags use karna generally safer and more reproducible approach hota hai.

11. Common Problems

❌ Port Already in Use

Agar host port 8080 already kisi application/container ke dwara use ho raha hai, to port mapping fail ho sakti hai.

Different host port use kar sakte hain: 

docker run -d --name my-nginx -p 8081:80 nginx

❌ Container Immediately Stops

Container ka main process exit ho gaya ho sakta hai. Container tabhi running rehta hai jab uska primary process active hota hai.

Check: 

docker ps -a
docker logs CONTAINER_NAME

❌ Image Not Found

Image name ya tag galat ho sakta hai.

Example: 

docker pull nginx
