  • cd node-docker-app → project directory ke andar enter karta hai.

Node.js Project Initialize Karein

Ye command automatically package.json file create karegi.

3. Step 2 — Node.js Application Create Karna

Ab project ke andar server.js file create karein.

server.js

const express = require("express");

const app = express();

const PORT = 3000;

app.get("/", (req, res) => {
    res.send("Hello from Node.js Docker Container! 🚀");
});

app.get("/about", (req, res) => {
    res.send("This application is running inside Docker.");
});

app.listen(PORT, () => {
    console.log(`Server running on port ${PORT}`);
});

Code Explanation

Code Purpose
require("express") Express framework ko application me import karta hai.
express() Express application create karta hai.
PORT = 3000 Application port 3000 par listen karegi.
app.get("/", ...) Root URL ke liye response define karta hai.
app.listen() Node.js server ko start karta hai.

Local Machine Par Test Karein

node server.js

Browser me open karein: 

http://localhost:3000
Expected Output:

Hello from Node.js Docker Container! 🚀

Agar local application successfully chal rahi hai, to Ctrl + C se server stop kar dein.

4. Step 3 — .dockerignore Create Karna

Docker image build karte waqt unnecessary files ko image ke build context me bhejne se bachane ke liye .dockerignore file useful hoti hai.

.dockerignore

node_modules
npm-debug.log
.git
.gitignore
Dockerfile
README.md
Why node_modules ignore kar rahe hain?

Hum host machine ke existing node_modules ko image me copy nahi karna chahte. Docker image ke andar dependencies npm install ke through install karna better hai.

5. Step 4 — Dockerfile Create Karna

Ab hum project ke root directory me ek file create karenge jiska exact naam hoga:

Dockerfile

Dockerfile me koi extension nahi hoti.

Dockerfile

# Use official Node.js image
FROM node:22-alpine

# Set working directory
WORKDIR /app

# Copy package files
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy application source code
COPY . .

# Application port
EXPOSE 3000

# Start application
CMD ["node", "server.js"]

Dockerfile ko Line-by-Line Samjho

Instruction Explanation
FROM node:22-alpine Node.js 22 Alpine based image ko base image ke roop me use karta hai.
WORKDIR /app Container ke andar /app working directory set karta hai.
COPY package*.json ./ package.json aur package-lock.json ko container ke /app me copy karta hai.
RUN npm install Container image build karte waqt Node.js dependencies install karta hai.
COPY . . Project ki remaining files image ke andar copy karta hai.
EXPOSE 3000 Document karta hai ki application container ke andar port 3000 use karti hai.
CMD ["node", "server.js"] Container start hone par Node.js application run karta hai.

🧠 Easy Analogy

Dockerfile ko ek recipe/instruction manual samjho.

Isme hum Docker ko batate hain:

  • Kaunsi base image use karni hai.
  • Files kahan copy karni hain.
  • Dependencies kaise install karni hain.
  • Application kaunsi port use karegi.
  • Container start hone par kya command run hogi.

9. Step 7 — Docker Image ko Run Karna

Ab hum newly created Docker image se container create aur start karenge.

Run Command

docker run -d --name node-app-container -p 3000:3000 node-docker-app:1.0

Command Breakdown

Option Purpose
-d Container ko detached/background mode me run karta hai.
--name node-app-container Container ko custom name deta hai.
-p 3000:3000 Host port 3000 ko container port 3000 se map karta hai.
node-docker-app:1.0 Jis image se container create karna hai.
Port Mapping:

HOST_PORT:CONTAINER_PORT

Yahan: 3000:3000

Browser → Host Port 3000 → Container Port 3000

15. Common Problems & Solutions

❌ Problem 1: Port Already in Use

Agar host machine ka port 3000 already kisi application ke dwara use ho raha hai, container start nahi hoga.

Solution

docker run -d \
  --name node-app-container \
  -p 3001:3000 \
  node-docker-app:1.0

Ab browser me: 

http://localhost:3001

❌ Problem 2: Container Immediately Stops

Sabse pehle logs check karein: 

docker logs node-app-container

Isse application ke startup error ko identify karne me help milegi.

❌ Problem 3: Image Build Fail

Dockerfile aur project files check karein. 

docker build -t node-docker-app:1.0 .

Build output me jis step par error aaye, us instruction ko check karein.

❌ Problem 4: Docker Daemon/Engine Not Running

Agar Docker engine running nahi hai to commands fail ho sakti hain.

Docker Desktop use kar rahe hain to Docker Desktop open karke ensure karein ki Docker engine ready hai.

16. Why Do We Create a Dockerfile?

Dockerfile ka main purpose application ke Docker image build process ko reproducible aur automated banana hai.

Agar Dockerfile nahi ho to hume container environment manually configure karna pad sakta hai.

Dockerfile me hum clearly define kar sakte hain:

  • Base image
  • Working directory
  • Dependencies
  • Application files
  • Ports
  • Startup command
DevOps Concept:

Dockerfile ko Infrastructure/Environment configuration ko code ke form me define karne ka practical example samjha ja sakta hai.
