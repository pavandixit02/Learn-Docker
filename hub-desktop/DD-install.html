🐳 Docker Desktop Installation

Complete step-by-step guide to install Docker Desktop, verify the installation, run your first container, and troubleshoot common problems.

1. What is Docker Desktop?

Docker Desktop is a desktop application that provides tools and a local environment for building, running, and managing containerized applications.

It is commonly used by developers and DevOps learners to work with Docker on their personal computers.

Simple Definition:

Docker Desktop allows you to use Docker locally through a graphical interface as well as the Docker command line.

Docker Desktop can help you:

  • Build Docker images
  • Create and run containers
  • Stop and restart containers
  • View container logs
  • Manage images
  • Work with Docker Compose
  • Manage Docker resources
  • Develop and test containerized applications locally

2. Before Installing Docker Desktop

Before installation, make sure your system meets the requirements for your operating system and Docker Desktop version.

💻 Hardware

A reasonably modern 64-bit computer with sufficient RAM and storage for your containers and images.

🌐 Internet

Internet access is useful for downloading Docker Desktop, images, updates, and dependencies.

🔐 Permissions

You may need administrator privileges to install Docker Desktop.

⚙️ Virtualization

Windows installations commonly require hardware virtualization and WSL 2 or another supported backend.

Important:

Docker Desktop requirements can change between versions. Always check the current official Docker Desktop documentation for your operating system before installation.

3. Docker Desktop Installation on Windows

1 Download Docker Desktop

Open the official Docker website and download the Docker Desktop installer for Windows.

Choose the installer that matches your system and current Docker documentation.

Tip:

Always download Docker Desktop from the official Docker website rather than an unknown third-party website.

2 Run the Installer

Open the downloaded Docker Desktop installer.

If Windows asks for administrator permission, allow the installer to continue.

3 Choose the Backend

During installation, Docker Desktop may provide configuration options related to its Linux/WSL 2 backend.

For most Windows users learning Linux containers, WSL 2 is the commonly used option.

Do not blindly change advanced options.

If you are a beginner, use the recommended configuration unless you have a specific reason to change it.

4 Complete Installation

Allow the installer to copy the required files and configure Docker Desktop.

Restart Windows if the installer requests it.

5 Start Docker Desktop

Open Docker Desktop from the Windows Start Menu.

Wait until Docker Desktop indicates that the Docker engine is running and ready.

6 Open PowerShell or Windows Terminal

Open a terminal and check whether Docker is available. 

docker --version

You should see the installed Docker CLI version.

4. Docker Desktop Installation on Ubuntu/Linux

Docker Desktop can also be installed on supported Linux distributions. The exact requirements and installation commands depend on the distribution and Docker Desktop version.

1 Check Your Ubuntu Version 

cat /etc/os-release

This command displays information about your Linux distribution.

2 Update Package Information 

sudo apt update

3 Download the Official Docker Desktop Package

Download the appropriate Docker Desktop package from Docker's official documentation for your Ubuntu release.

Why not use a random command from an old tutorial?

Docker Desktop installation procedures can change. Always verify the package and installation instructions against the current official Docker documentation.

4 Install the Package

After downloading the supported Debian package, install it using the package manager. 

sudo apt install ./docker-desktop-*.deb

Use the actual downloaded package filename if the wildcard does not match your file.

5 Start Docker Desktop 

systemctl --user start docker-desktop

This starts Docker Desktop for the current user when the installed version uses this service configuration.

6 Check Docker

docker --version

If Docker is installed and available, the command should display the Docker CLI version.

For Ubuntu learners:

If your main goal is learning Docker and DevOps on Ubuntu, Docker Engine can also be installed directly without Docker Desktop. Docker Desktop is particularly useful when you want its desktop UI and integrated local development experience.

5. Verify Docker Desktop Installation

After installation, do not assume Docker is working. Always verify it using the CLI.

Check Docker Version

docker --version

Check Docker Information

docker info

Check Running Containers

docker ps

Check All Containers

docker ps -a

✅ Installation Verification

If Docker Desktop is running and commands such as docker info work successfully, your local Docker environment is generally ready for container work.

6. First Docker Container — Practical Example

Now let's verify Docker by running a real container. We will use the official Nginx image.

Step 1 — Pull Nginx Image

docker pull nginx

Docker downloads the Nginx image from a container registry.

Step 2 — Check Image

docker images

Step 3 — Run Nginx Container

docker run -d --name my-nginx -p 8080:80 nginx

Command Explanation

Part Meaning
docker run Creates and starts a container.
-d Runs the container in detached/background mode.
--name my-nginx Gives the container a custom name.
-p 8080:80 Maps host port 8080 to container port 80.
nginx The image used to create the container.

Step 4 — Check Container

docker ps

Step 5 — Open Browser

Open: 

http://localhost:8080

If the container is running correctly, you should see the Nginx welcome page.

→

→
localhost:8080

Step 6 — Stop Container

docker stop my-nginx

Step 7 — Remove Container

docker rm my-nginx

7. Using Docker Desktop GUI

Docker Desktop also provides a graphical interface. You can use it to inspect and manage Docker resources without entering every command manually.

📦 Containers

View containers, their status, logs, ports, and other information.

🖼️ Images

View locally stored Docker images.

💾 Volumes

Manage Docker volumes used for persistent data.

🌐 Networks

Inspect Docker networks used by containers.

8. Common Installation & Runtime Problems

❌ Error: Docker command not found

The Docker CLI may not be installed correctly, may not be available in PATH, or Docker Desktop/Engine may not be running.

Check: 

docker --version

❌ Error: Docker Engine is not running

Docker Desktop may be installed but its backend may not currently be running.

Open Docker Desktop and wait until it reports that Docker is running.

❌ Error: WSL 2 related problem on Windows

Docker Desktop on Windows may depend on WSL 2 and virtualization configuration.

Check that WSL is installed correctly and that hardware virtualization is enabled in firmware when required.

❌ Error: Permission denied on Linux

Linux users can sometimes encounter Docker socket permission problems.

First verify whether Docker is working with appropriate privileges and then configure Docker group access according to Docker's official Linux instructions.

9. Important Commands After Installation

# Check Docker version
docker --version

# Show Docker system information
docker info

# List images
docker images

# List running containers
docker ps

# List all containers
docker ps -a

# Pull an image
docker pull nginx

# Run a container
docker run -d --name web nginx

# Stop a container
docker stop web

# Start a stopped container
docker start web

# Remove a container
docker rm web

# Remove an image
docker rmi nginx

10. Docker Desktop vs Docker Engine

Docker Desktop Docker Engine
Desktop application/development environment. Core container technology used to build and run containers.
Provides GUI and developer tooling. Provides the core daemon/API/CLI-based container functionality.
Commonly used on developer workstations. Can be installed directly on supported Linux servers.
Convenient for local development. Common foundation for server-side container workloads.

11. Docker Installation Best Practices

  • Download Docker software from official Docker sources.
  • Keep Docker Desktop updated when appropriate.
  • Do not install random Docker packages from unknown websites.
  • Learn both Docker GUI and Docker CLI.
  • Practice Docker commands regularly.
  • Understand images, containers, volumes, and networks before moving to advanced topics.
  • For DevOps, focus especially on CLI, Dockerfile, Docker Compose, registries, CI/CD, and troubleshooting.
